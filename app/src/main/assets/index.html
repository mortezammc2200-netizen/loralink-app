Users
Users (up to 8). Each gets a path like http://IP/x1. Same network = LAN private chat. Different networks / devices = LoRa private. No public visibility of others' messages.
Username 2-16 characters, password at least 4. The personal link is this address + /username (for example /a1). Everyone you create here belongs to the building name above.
Channels
A channel is a private group with its own passphrase. Only nodes that add the same name and passphrase can read it (up to 3). A repeater must add the channel too to forward its messages.
Group checklist

Base64 key from the Meshtastic app, or default (the public key), or none. Leave empty to keep the current key.

Not available in Meshtastic mode: edit, delete, read receipts, private channels and fragmented long messages (long texts are sent as several messages).

Alerts & hardware
Buzzer & LED
Buzzer
LED
Wiring: one buzzer pin to the chosen GPIO, the other to GND (an LED needs a resistor of about 330 ohm to GND). One short beep = new message, three beeps = alert, siren = SOS. The LED pulses on traffic, blinks slowly while messages are unread and flashes fast for alerts. Only pins that are safe to use are listed.

When enabled, normal beeps and LED are silent between these times. SOS still works unless you turn that off too. Device clock must be set (Wi-Fi NTP or phone time).
Morse signal
Idle
Plays the message as Morse code on the device LED and/or buzzer. Remote Morse lets another node make this device play without a phone connected. Short button press = confirm received; double press = problem. SOS always has priority. Switch LED/buzzer on in Buzzer & LED first.
Button actions
Single press is Ping by default (while remote Morse is playing, a single press confirms it and a double press reports a problem). Hold 5 s = SOS, hold 30 s = factory reset (the LED blinks fast while held). Location needs a position: open the app once with GPS or enter coordinates.
Location & safety
Location & GPS
Browsers only share your phone's GPS with secure (HTTPS) pages. This app is served by the device over plain HTTP, so the browser blocks location until you mark this address as trusted. It is a one-time step on Android Chrome. iPhone/Safari has no such option, so use manual coordinates below.
GPS status--
Current position--
  1. Copy the flags address, paste it in Chrome's address bar and open it.
  2. Find Insecure origins treated as secure and set it to Enabled.
  3. In the text box type this address: http://192.168.4.1
  4. Tap Relaunch, reconnect to the device Wi-Fi and reopen this page.
  5. Make sure phone Location is on, then tap Test GPS below and choose Allow.
Chrome does not let web pages open chrome:// links, so the address must be pasted by hand.
