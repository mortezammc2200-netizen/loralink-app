# LoRa Link – برنامهٔ اندروید (بلوتوث)

همان صفحهٔ وب دستگاه، داخل یک WebView؛ ولی همهٔ درخواست‌ها (`/api/...`) به‌جای Wi-Fi با **بلوتوث BLE** می‌روند.
رابط کاربری داخل برنامه است (`app/src/main/assets/index.html`) و از روی فریمور کپی می‌شود.

## ۱) فریمور (یک بار)
1. در Arduino IDE کتابخانهٔ **NimBLE-Arduino** را نصب کنید (Library Manager).
2. در `lora_messenger.ino` خط `#define USE_BLE_BRIDGE 0` را به `1` تغییر دهید.
3. Partition Scheme را روی یکی از گزینه‌های بزرگ‌تر بگذارید، مثلاً **Huge APP** (برنامه + بلوتوث جا می‌خواهد). اگر فایل‌سیستم لازم دارید (ارسال فایل)، گزینه‌ای را انتخاب کنید که فایل‌سیستم هم دارد.
4. آپلود کنید. از این به بعد Wi-Fi مثل قبل کار می‌کند و بلوتوث هم فعال است.
5. با Wi-Fi وارد صفحه شوید ← Settings ← Tools & preferences ← **Bluetooth (Android app)** ← «Show pairing PIN». این PIN شش‌رقمی را موقع جفت‌شدن لازم دارید.

## ۲) برنامه
1. پوشهٔ `lora_messenger_android` را در **Android Studio** باز کنید (Sync اتوماتیک انجام می‌شود).
2. هر بار صفحهٔ وب فریمور را عوض کردید: `python3 tools/sync_ui.py` (مسیر پیش‌فرض `firmware/lora_messenger/assets.h`).
3. Run روی گوشی (Android 8 به بالا) یا Build ← Build APK.

## استفاده
- **Scan** ← دستگاه `LoRaLink-xxxx` را انتخاب کنید ← اولین بار گوشی PIN می‌خواهد.
- «Personal link name» همان نام لینک شخصی کاربر است (مثل `a1`)؛ برای ادمین خالی بگذارید.
- GPS و میکروفون بدون مشکل HTTP کار می‌کنند (برنامه صفحه را با https داخلی باز می‌کند).
- لینک Organic Maps مستقیم برنامه را باز می‌کند.

## نکته‌ها / محدودیت‌ها
- هر درخواست حدود ۲۰ تا ۲۰۰ میلی‌ثانیه طول می‌کشد؛ برای چت کافی است. فایل‌های بزرگ (ویدیو) روی بلوتوث کند هستند.
- در حال حاضر اتصال فقط وقتی برنامه باز است برقرار می‌ماند. اعلان پیام وقتی برنامه بسته است (Foreground Service) هنوز اضافه نشده.
- پل بلوتوث درخواست را به وب‌سرور خود ESP32 می‌فرستد (`WiFi.softAPIP():80`). اگر AP خاموش باشد کار نمی‌کند.
- این کد در محیط من کامپایل و روی گوشی واقعی تست **نشده**؛ لطفاً با دو گوشی/دو دستگاه امتحان کنید و خطاها را بفرستید.

## ساخت APK بدون Android Studio (GitHub Actions)
1. این پوشه (`lora_messenger_android`) را در یک مخزن GitHub بریزید (محتوا باید در ریشهٔ مخزن باشد).
2. تب **Actions** ← «Build APK» ← **Run workflow**.
3. بعد از چند دقیقه از بخش Artifacts فایل `LoRaLink-debug-apk` (حاوی `app-debug.apk`) را دانلود و روی گوشی نصب کنید (نصب از منابع ناشناس را اجازه دهید).
